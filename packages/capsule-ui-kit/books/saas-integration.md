# SaaS shell integration

The production v2 entry imports `SaasShellGrid.vue`. The build enables Vue Options API, and the consumer registers its labels, groups, icons, capsule components and placement with the shared AppShell. The kit owns navigation, topbar, search palette, theme toggle, workspace settings, status and the Terminal shortcut. DockWorkspace remains the sole layout owner.

OpenVue receives the per-document style nonce generated by the consuming application. The host supplies a meta element whose name ends in `-style-nonce` (for example, `capsule-style-nonce`); this also supports existing consumer-specific prefixes without encoding a product name in the kit. Missing nonce refuses installation. Aura remains an adapter over the kit token authority. The admitted declarations do not specify `darkModeSelector`: AUSENTE — no inventar. The toggle changes kit scheme tokens; no unproven vendor selector is configured.

The installed xterm sources bypass `documentOverride` in browser-service construction and row-factory construction. `capsule-ui-kit/xterm-csp` exports a build plugin that corrects those exact vendor anchors and refuses drift. The declared document override then supplies nonce-bearing style elements and applies generated row declarations through CSSOM. No installed vendor file, global document method or DOM prototype is changed. Consumers using TerminalCapsule must install this build plugin and provide the document nonce.

TerminalCapsule receives a closed facade from its consumer. It advertises only discovered launchers, requires explicit opt-in when main advertises player mode, and uses real xterm/FitAddon with MultiSlot sessions. `externalAiSlot` on CapsulePanel delegates the canonical slot anchor to that embedded MultiSlot. Inactive session hosts remain mounted; folding and ordinary Hide/Show preserve the session. Unsupported attach/reconnect remains disabled. CLI/model readiness metadata is AUSENTE — no inventar; running PTYs retain unknown activity until an authoritative exit rather than deriving readiness from output.
